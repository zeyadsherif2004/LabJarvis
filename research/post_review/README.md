# September evaluation extensions

This directory contains experiments added after the July E1-E4 evaluation.
It does not overwrite those outputs. Every run records its configuration and
input hashes; the [provenance record](PROVENANCE.md) distinguishes the September
results from the original experiment commit.

The public-protocol set is source-independent but not human-adjudicated. The
model comparisons use synthetic media unless a manifest explicitly says
otherwise. Nothing here is evidence about human usability, live acoustics,
real photographed labels, or laboratory safety.
